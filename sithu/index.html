About

I build AI systems that run on hardware you own, and robots that use them. My background is mechatronics and embedded systems: I started with Arduino and microcontrollers, moved to ROS navigation and robot models at ROM Robotics, and now work on large language model agents: memory, retrieval, tool use and serving models on a single GPU.

Most of my recent work comes together in AON, a self-hosted AI agent I designed, built and shipped end to end: the agent loop, the model serving, the web and Android apps, the Python package and the MCP server.

Featured: AON

🛰️ AON: a self-contained AI agent on your own GPU

PyPI: aon-agentOfficial MCP RegistryWeb + Android~600 testsMIT licensed

A private AI agent that runs entirely on local hardware, with no cloud LLM. It answers questions, runs tools (files, shell, web search, maps), remembers the user across chats, reads their documents and extends itself with new models, skills and MCP servers.

PythonFastAPIvLLMOllama RAG (SQLite FTS5 + vectors)MCP server & clientWebSocket AndroidCloudflare Tunnel

What I built: an agent loop with an approval gate for shell and file actions; long-term memory with semantic search; a hybrid-search document library; exact-token context fitting against the model server; a 27B model served with vLLM on one RTX 4090; OpenStreetMap routing on a 3D globe; a pip-installable CLI; and an MCP server so Claude Desktop, Claude Code and Cursor can use AON as a tool.

About

I build AI systems that run on hardware you own, and robots that use them. My background is mechatronics and embedded systems: I started with Arduino and microcontrollers, moved to ROS navigation and robot models at ROM Robotics, and now work on large language model agents: memory, retrieval, tool use and serving models on a single GPU.

After an MSc in AI and Machine Learning at Liverpool John Moores University, where my dissertation won the Best Dissertation Award, I now work there as a Research Assistant on applied AI and robotics, with work published at IEEE DeSE and in review on emotion recognition for social robots. My research focuses on memory in language models: what survives in their hidden states, and how that state can become lasting memory for agents and robots. I am also building J.A.R.V.I.S 0021, an open humanoid robot for teaching robotics. Most of my own recent software comes together in AON, a self-hosted AI agent I designed, built and shipped end to end: the agent loop, the model serving, the web and Android apps, the Python package and the MCP server.

Real-Time Autonomous Navigation on a Raspberry Pi with Deep Learning and Sensor Fusion

B. Orimba, O. Aldhaibani, S. Ye Htun, R. Mohammed

2025 18th International Conference on Development in eSystem Engineering (DeSE), Bucharest, Romania · pp. 1–6 · doi:10.1109/DeSE68208.2025.11367895

A low-cost, end-to-end self-driving prototype on an RC car with a Raspberry Pi 4. A camera and an ultrasonic sensor are combined by late fusion to read traffic lights and avoid obstacles. A fine-tuned SSD-MobileNetV2 reaches 0.812 mAP (COCO), and after INT8 quantisation and ONNX Runtime it runs in real time at about 286 ms per frame within the Pi's thermal limits. The car stops on red or amber and moves only on a confirmed green with a clear path.

Pep-FER: A Facial Emotion Recognition System using EfficientNetB0 with a Pepper Social Robot

D. Reilly, S. Ye Htun, P. Fergus, C. Chalmers, M. Taylor, S. Thompson

Liverpool John Moores University · supported by the Liverpool City Region Life Sciences Investment Zone (TALASCM project)

Social robots could support care for older adults and people living with dementia, for example in Cognitive Stimulation Therapy, but they need to read people's emotions. We built a facial emotion recognition system for the Pepper robot using the NAOqi API and an EfficientNetB0 backbone, trained on a merged, balanced dataset. The best model reaches 99.6% accuracy on the test set, and the system runs on Pepper alongside its existing functions without slowing the robot down.

Design and Implementation of a Full Duplex Conversational Speech System

S. Ye Htun, D. Reilly · Liverpool John Moores University

A browser interface for full-duplex spoken conversation, where the user can interrupt the assistant mid-sentence (barge-in). It combines short-lived session credentials, WebSocket audio, server-side voice activity detection and application-level cancellation; a generation counter stops audio from an interrupted reply from coming back after late callbacks. A FastAPI service protects the API key, applies rate limits and exports metrics. In a five-minute observation window it served 3,397 requests with no HTTP errors, and early client measurements put the gap between the end of the user's turn and the first audible reply at about 0.9 s.

Physics-Informed Hybrid Digital Twin for Photovoltaic Predictive Maintenance (PI-HDT)

Most solar-panel digital twins are purely data-driven and are rarely tested on real faults. PI-HDT couples a mechanistic performance model with a machine-learning residual, constrained by physics (the datasheet temperature coefficient and a monotonic response to irradiance). It synthesises realistic faults with the single-diode model, tracks drifting model coefficients to explain the cause of degradation, and uses conformal prediction intervals to decide when to raise an alarm, evaluated across sites and seasons on operator-labelled field faults.

Research

My research asks how language models can keep and use memory over time: what survives inside a model's hidden states, and how that state could become real long-term memory for agents and robots.

PhD research proposal

Persistent State Memory in Hybrid Language Models

Language models forget everything between sessions. Hybrid models such as Qwen3.8 replace most attention layers with linear-attention layers (Gated DeltaNet) that summarise all past text in a fixed-size recurrent state, small enough to save, store and reload. The proposal will (1) derive and test the capacity and interference limits of these states as persistent memory, (2) design methods to save, combine and reload states together with a small set of attention key-value pairs, and (3) build a verifier-gated continual-learning loop that writes only checked improvements to memory. Evaluation uses synthetic tasks and public benchmarks (BABILong, LongMemEval, MemoryAgentBench) against strict, compute-matched baselines.

Recoverability of Token Identity in Delayed Transformer Hidden States

A preregistered experimental programme on frozen Qwen3-4B. Does the exact identity of a token survive inside later hidden states after the model has read many more tokens? At the token's own position it clearly does: top-1 recovery of 40.2% over a 151,655-token vocabulary, against a matched null of 0.5%. Sixty-four tokens later, direct, linear, multi-position and non-linear decoders all failed to beat matched structural nulls, which suggests apparent "memory" often reflects structure (token family, length, position) rather than the exact token. The programme separates these effects with held-out tests, matched nulls and bootstrap intervals, and is now moving to a new direction (R11).

LatentRecall: persistent hidden-state memory for frozen language models

Can a model gain lasting memory without changing its weights or keeping the conversation as text? LatentRecall stores the model's own hidden-state traces of new experiences and uses them to reconstruct information after the original context is gone.

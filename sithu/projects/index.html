AON: a self-contained AI agent on your own GPU

A private AI agent that runs entirely on local hardware, with no cloud LLM. It answers questions, runs tools (files, shell, web search, maps), remembers the user across chats, reads their documents and extends itself with new models, skills and MCP servers.

What I built: an agent loop with an approval gate for shell and file actions; long-term memory with semantic search; a hybrid-search document library (SQLite FTS5 and vectors); exact-token context fitting against the model server; a 27B model served with vLLM on one RTX 4090; OpenStreetMap routing on a 3D globe; a pip-installable CLI; web and Android apps; and an MCP server so Claude Desktop, Claude Code and Cursor can use AON as a tool.

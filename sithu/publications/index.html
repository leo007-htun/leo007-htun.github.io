Real-Time Autonomous Navigation on a Raspberry Pi with Deep Learning and Sensor Fusion

B. Orimba, O. Aldhaibani, S. Ye Htun, R. Mohammed

2025 18th International Conference on Development in eSystem Engineering (DeSE), Bucharest, Romania, pp. 1–6. doi:10.1109/DeSE68208.2025.11367895

A low-cost, end-to-end self-driving prototype on an RC car with a Raspberry Pi 4. A camera and an ultrasonic sensor are combined by late fusion to read traffic lights and avoid obstacles. A fine-tuned SSD-MobileNetV2 reaches 0.812 mAP (COCO), and after INT8 quantisation and ONNX Runtime it runs in real time at about 286 ms per frame within the Pi's thermal limits.

Pep-FER: A Facial Emotion Recognition System using EfficientNetB0 with a Pepper Social Robot

D. Reilly, S. Ye Htun, P. Fergus, C. Chalmers, M. Taylor, S. Thompson

Liverpool John Moores University · supported by the Liverpool City Region Life Sciences Investment Zone (TALASCM project)

Social robots could support care for older adults and people living with dementia, for example in Cognitive Stimulation Therapy, but they need to read people's emotions. We built a facial emotion recognition system for the Pepper robot using the NAOqi API and an EfficientNetB0 backbone, trained on a merged, balanced dataset. The best model reaches 99.6% accuracy on the test set, and the system runs on Pepper alongside its existing functions without slowing it down.

Design and Implementation of a Full Duplex Conversational Speech System

S. Ye Htun, D. Reilly

A browser interface for full-duplex spoken conversation, where the user can interrupt the assistant mid-sentence (barge-in). It combines short-lived session credentials, WebSocket audio, server-side voice activity detection and application-level cancellation; a generation counter stops audio from an interrupted reply from coming back after late callbacks. In a five-minute observation window the service handled 3,397 requests with no HTTP errors, and early client measurements put the gap between the end of the user's turn and the first audible reply at about 0.9 s.

Physics-Informed Hybrid Digital Twin for Photovoltaic Predictive Maintenance (PI-HDT)

Most solar-panel digital twins are purely data-driven and rarely tested on real faults. PI-HDT couples a mechanistic performance model with a machine-learning residual constrained by physics, synthesises realistic faults with the single-diode model, tracks drifting model coefficients to explain degradation, and uses conformal prediction intervals to decide when to raise an alarm, evaluated across sites and seasons on operator-labelled field faults.
